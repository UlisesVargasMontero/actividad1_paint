# Actividad 1
Original de Paint.py

## Descripción

El juego trata de dibujar formas y cambiar su color mediante teclas.

## Cómo se usa
- Figuras: l linea, s cuadrado, c círculo, r rectángulo, t triángulo.
- colores: shift + K negro, W blanco, G verde, B azul, R rojo, Y amarillo.
- Cada figura se dibuja con dos clics: inicio y el fin.
